# Добро пожаловать, Даниил!

Приветственный сайт на GitHub Pages. При открытии показывает современный экран приветствия, дату встречи и галерею фотографий.

## Как добавить фотографии

1. Загрузи фото в папку `images`.
2. Любые имена и форматы (`jpg`, `jpeg`, `png`, `gif`, `webp`, `avif`, `svg`, `bmp`) поддерживаются.
3. GitHub Actions автоматически обновит `images.json`.
4. GitHub Pages обновит сайт, и фото появятся в галерее.

Если фото не показались сразу, подожди 1-2 минуты: Actions и Pages завершаются после push.

## Локальный просмотр

Можно открыть `index.html` напрямую. Галерея также умеет читать каталог через GitHub API, если `images.json` ещё не создан.

## Безопасность

Сайт полностью статический. Фотографии публикуются в репозитории, поэтому не загружай приватные данные.
